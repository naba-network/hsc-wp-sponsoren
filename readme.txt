Manages the sponsors and partners of the club as a single source of truth.

== Description ==

Sponsors are maintained once in the WordPress admin, grouped by category (Hauptsponsor, Premium, Sponsoren, Gönner).
The plugin updates itself from GitHub releases.

== Installation ==

1. Download `hsc-sponsoren.zip` from the latest GitHub release.
2. Upload it under Plugins > Add New > Upload Plugin and activate it.
3. Later versions appear as regular updates in the WordPress admin.
